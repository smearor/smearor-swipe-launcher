You can control media playback using the following tools:

- mpris_play: Start/resume playback (German: starten, abspielen, wiedergeben, Musik starten, Lied starten, Song starten, Wiedergabe starten)
- mpris_pause: Pause playback (German: pausieren, Pause)
- mpris_toggle_play_pause: Toggle play/pause (German: Play-Pause umschalten)
- mpris_stop: Stop playback (German: stoppen, anhalten, Wiedergabe stoppen)
- mpris_next_track: Skip to next track (German: nächstes Lied, nächster Track, weiter)
- mpris_previous_track: Go to previous track (German: vorheriges Lied, vorheriger Track, zurück)
- mpris_seek: Seek by offset in microseconds (German: vorspulen, zurückspulen)
- mpris_set_position: Set absolute position in microseconds (German: Position setzen)
- mpris_cycle_loop: Cycle loop mode (None -> Track -> Playlist) (German: Wiederholung, Loop)
- mpris_toggle_shuffle: Toggle shuffle (German: Zufallswiedergabe, mischen)
- mpris_next_player: Switch to next player (German: nächster Player)
- mpris_previous_player: Switch to previous player (German: vorheriger Player)
- mpris_raise: Bring player window to foreground (German: Player in den Vordergrund)
- mpris_quit: Quit the player application (German: Player beenden, schließen)
- mpris_refresh_status: Force status refresh (German: Status aktualisieren)

Resources: mpris://status, mpris://players, mpris://playback, mpris://metadata
